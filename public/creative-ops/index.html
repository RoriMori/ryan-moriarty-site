AI + Automation

Where AI lives in the work
and how I use it

AI is a tool I use to do better work, faster. The judgment, the relationships, the creative instincts stay human. The goal is always the same: work that connects with the right people and means something to the business.

The order matters
Automation

Logic-based, no model. Cheapest and most reliable. Start here.

GenAI

Model-generated output. Copy, concepts, variations, summaries.

Agentic AI

Multi-step, goal-directed. Highest value. Requires a mature foundation.

Left to right. Don't skip steps.

Beyond the workflow

Beyond producing work, AI can help teams build and run better systems.

Auditing what exists

Faster gap analysis and pattern spotting across inherited systems, tools, and workflows

Reading demand data

Volume, types, sources. Surfaces patterns that would take a team weeks to pull manually

Getting docs off the ground

SOPs, RACIs, playbook drafts. AI gets the team to a working first draft faster

Keeping the system honest

Ongoing sense-checking as things change, flagging drift before it becomes a problem

Under the hood

A few things that make the difference between AI that helps and AI that wastes your time.

Right tool for the job

Not every problem needs the same model or approach

Connecting it to the stack

Getting AI to actually talk to the tools already in use

How you structure the input matters

Context architecture, clear instructions, thinking about what the model actually needs

Knowing when not to trust it

Hallucination awareness, output validation, keeping a human in the loop

Not burning tokens on noise

Managing context deliberately so performance stays high

Smart instructions

Prompts and system instructions built for consistency, not one-offs
